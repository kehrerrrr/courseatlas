# 方法说明（报告素材）

## 问题与数据

目标：使用用户输入的英文兴趣关键词、难度筛选和已完成课程列表，提供至多五个唯一的真实课程标题，并解释匹配依据。已完成课程仅为本次用户输入，不代表数据中已有真实学习历史。

使用 siddharthm1698 的 Kaggle Coursera Course Dataset。原始 891 行，六个业务字段：标题、机构、证书类型、评分、难度、选课人数。原始索引列忽略。实际统计和文件哈希由 analysis.py 写入 cleaning_summary.json；最终 888 个唯一课程标题。来源为历史快照，不能据此判断当前开课情况。

## 清洗

去除标题和字符串字段前后空格，将内部连续空白变成单空格；用于去重的标题键使用 Unicode NFKC 及 casefold，展示标题保留实际字符。空标题删除。同名标题优先选人数高、评分高的行，最后按原始行顺序确定。人数支持 14k、1.3m、32,000 等；非法数据保留为空。评分转数值，0–5 外视为缺失。其他缺失分类显示 Unknown；该词是缺失标记，不是新增机构或证书。输出按标题键稳定排序。

## 热门基线

令 e 为人数，r 为评分。L = min-max(log1p(e))，R = clip(r,0,5)/5，B0 = 0.7L + 0.3R；再令 B = min-max(B0)。这些归一化均在完整清洗目录上计算，之后才筛选。全相同特征的 min-max 结果取零。缺失人数/评分仅在基线计算中取零，不修改展示数据；因此未知质量可能受罚。B 是目录内相对热门程度，不是学习效果或真实流行趋势预测。

每个用户在相同难度和排除条件下具有同样的热门排序，兴趣不影响该基线。

## 个性化模型与拟合

在真实标题和查询上使用同一整词、大小写无关的确定性映射：math/maths→mathematics、AI→artificial intelligence、ML→machine learning、stats→statistics。仅匹配完整单词，NFKC 及空白规范化后执行；不扩写词表之外的概念，不改动展示标题、原始文件或清洗数据。理由中的词项可能是规范化词，如 AI 显示 artificial intelligence。该规则不能消除标题歧义，也不支持完整语义匹配。

在规范化后的真实 course_title 上拟合 TfidfVectorizer(stop_words="english", ngram_range=(1,2))。拟合意味着从标题学习词表和文档频率，用默认平滑 IDF 与 L2 归一化形成稀疏矩阵；没有标签、优化损失、训练/测试用户切分或协同过滤。对输入查询使用同一词表变换，计算与每个标题的余弦相似度 S。

先应用难度筛选和已学标题排除。对 S>0 的匹配项按 M=0.85S+0.15B 降序排序；同分再按 S 和标题键确定次序。如不足五项，将 S=0 的候选按 B 排序补位，清晰标记 Popularity fallback。补位不会挤走标题匹配项。空白、纯英文停用词或词表外关键词得到全热门补位；候选不足五门时不会制造新课程。

理由仅显示查询与标题共同的词表项；不推断课程内容、技能或先修要求。M 和 B 分开标注，均不是学习成功概率。

## 轻量参数比较

对三组明确标为 synthetic 的画像（数据科学、商业金融、心理与幸福感）运行四套配置：unigram/(1,2)-gram × 热门权重 0.15/0.30，并保留同条件热门基线。model_comparison.csv 保存全部实际推荐，diagnostics.csv 保存返回条数、唯一性、相似度、匹配与补位数量。

选用 (1,2)-gram 和 0.15：bigram 可表示 machine learning、data science 等词组；较低热门权重让标题相关性占主导。这是可解释的定性选择，没有宣称验证集最优。比较不同词表的余弦数值不能直接当作优劣；检查实际标题和补位才具有解释意义。人工标签补齐后可对比画像内 Precision@5，但三个主观合成画像不支持总体效果或因果提升结论。

## 评价与局限

真实标签留空，未经完整人工标注输出 “Not evaluated: human labels required.”。仅在某模型/画像恰有五个不同课程、rank 为 1–5、五个 0/1 标签有效时计算 Precision@5 = 相关条数/5。少于五个推荐时不计算该指标。脚本保留相同键的既有标签，不能自动证明标签由谁填写；人工标注流程由团队负责。

事实诊断：目录覆盖率只计算所选模型在三个合成画像 Top-5 中出现的唯一标题数/目录大小，不能外推至真实人群。测试验证去重、排除、难度、真实字段、空白/OOV、部分补位与解析。无用户总体、无完整相关课程集合，所以不报告 Recall 或真实用户准确率。未来可收集有授权的课程描述、人工相关性和真实反馈，再评价语义匹配及冷启动方法。

## 界面对比说明

Personalized 为默认模式，显示本次结果中匹配数、补位数和筛选后全部候选数。Popular 只使用原有热门基线并明确忽略兴趣词，不显示个性化公式。两组实际 Top-5 使用相同难度和排除条件；共享课程显示相对另一组的上升/下降名次，缺席另一组 Top-5 时不推断名次。没有新增评价指标或人工标签。
